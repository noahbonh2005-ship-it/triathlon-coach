TRIATHLON COACH — GILEPPE TROPHY 2027

Version 1 : application personnelle locale / PWA.

CONTENU
- Aujourd'hui : séance(s) du jour
- Planning : 4 premières semaines
- Historique : séances réalisées
- Progression : vue simple
- Fiches détaillées de musculation
- Compte rendu après séance
- Données sauvegardées dans le navigateur (localStorage)

PROGRAMME ACTUEL
Lundi : UPPER A
Mardi : Course
Mercredi : ANTERIOR + Vélo
Jeudi : POSTERIOR
Vendredi : Course
Samedi : UPPER B
Dimanche : Vélo

Pour utiliser comme une vraie PWA sur téléphone, héberger ces fichiers sur un hébergement HTTPS, puis utiliser "Ajouter à l'écran d'accueil".

IMPORTANT
Les données sont stockées localement dans le navigateur. Cette V1 n'a pas de compte ni de synchronisation cloud.
